# Изменения проекта

Небольшие исправления можно присылать через PR. Для изменения межworkflow-контракта сначала опишите затронутые producer/consumer и способ перехода между версиями.

Перед PR:

```bash
python scripts/check.py --rebuild
```

Если меняется Function/Condition, добавьте тест на конкретный сбой. Для изменения guards нужен пример отклонённого действия. Если меняется CI, проверьте callback и привязку к PR head SHA.

В описании достаточно указать проблему, новое поведение и выполненные проверки. Изменения инфраструктуры, требующие живого стенда, отмечайте отдельно. Секреты, журналы с credentials и виртуальные диски в PR не включаются.
