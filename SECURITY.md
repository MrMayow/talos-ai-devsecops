# Сообщения об уязвимостях

Не прикладывайте рабочие PAT, kubeconfig или необработанные execution exports к публичным issues. Для чувствительной находки используйте GitHub **Security → Report a vulnerability**, если private reporting включён. Если он недоступен, создайте issue только с просьбой согласовать закрытый канал, без деталей эксплуатации и секретов.

Укажите затронутый файл/профиль, версию SIM/Gitea и минимальный обезличенный сценарий. Это лабораторный проект без гарантированного срока поддержки. Подробные ограничения описаны в [docs/security.md](docs/security.md).
